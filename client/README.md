# CipherNote Client

This folder contains the React + Vite frontend for CipherNote.

## Scripts

- `npm run dev` starts the local development server.
- `npm run build` creates the production build.
- `npm run preview` serves the production build locally.
- `npm test` runs the frontend Jest suite.

## Environment Variables

- `VITE_API_BASE_URL` points to the backend API base URL.

Example:

```bash
VITE_API_BASE_URL=http://localhost:5000/api
```

## Frontend Scope

The client handles:

- Authentication UI (register/login)
- Protected note views
- Create, edit, delete, and search interactions
- Rich text editing via TipTap

For full project setup, deployment details, and API documentation, see the root README.
